# AIra

Исследовательская программа: **мозго-подобные алгоритмы для энергоэффективного ИИ**.
Цель — не «ещё один SOTA», а максимальное приближение к организации и энергоэффективности мозга средствами алгоритмов (событийность, локальное обучение, разрежение, множественные временны́е шкалы), с возможностью обучать и использовать модели на этом стеке.

## Код и эксперименты

- [`src/aira/`](src/aira/) — ядро: `pc.py` (равновесное обучение, солверы Richardson/Jacobi/зонный/Multigrid), `events.py` (σ-δ кодек), `energy.py` (энергопрокси).
- [`experiments/EXP01_REPORT.md`](experiments/EXP01_REPORT.md) — **трилемма локального кредита**: FF-11/FF-12 подтверждены [Э], H-14 ✓ (×16–23), H-18 ✓ (мультигрид, наклон 0,11 vs 2,00).
- [`experiments/EXP02_REPORT.md`](experiments/EXP02_REPORT.md) — **σ-δ событийное кодирование**: FF-1/FF-3 подтверждены, канал σ-δ даёт ×8–40 бит экономии.
- [`benchmarks/RIG_REPORT.md`](benchmarks/RIG_REPORT.md) — **M1, стойка**: генеративный корпус, char-токенизатор, GPT-micro бейзлайны (torch CPU), энергопрокси v2; ворота M1 закрыты.
- [`corpus_external/README.md`](corpus_external/README.md) — реестр внешних корпусов: opus46 (англ. рассуждения, частично верифицирован по золоту GSM8K, карантин 261 строки), gsm8k, wikitext2, russian_lit (Толстой); правила добавления и проверки.
- [`experiments/EXP04_REPORT.md`](experiments/EXP04_REPORT.md) — **мост обучения**: PC против BP на посимвольной LM — ppl +3,5% при равных шагах; найден механизм деградации выравнивания и рецепт для M2.
- [`experiments/EXP05_REPORT.md`](experiments/EXP05_REPORT.md) — **вспоминание по крючку**: DAM-стор, 12 800 эпизодов безошибочно, ×10³–10⁴ дешевле KV-скана; H-21/H-22 ✓; обход C5.
- [`experiments/EXP06_REPORT.md`](experiments/EXP06_REPORT.md) — **живая память**: стор на живом тексте («Кавказский пленник» + фон ×24 из «Войны и мира»): cloze 0.998, забывания нет, ручная сюжетная батарея 9/12, гейт чужих 0.946 (погранично); H-23 ✓/⚠.
- [`experiments/EXP07_REPORT.md`](experiments/EXP07_REPORT.md) — **зонный кирпич M2**: предельный цикл Эйлера и лекарство (BB×сторож энергии, min-cos 0.86 vs минус у Эйлера), событийный солвер (−84..94% работы бесплатно), честный фронтир σ-δ шины; H-24 ✓/✗/✓/фронтир.
- [`experiments/EXP08_REPORT.md`](experiments/EXP08_REPORT.md) — **рекуррентный носитель (M3 v0)**: разносная спираль найдена и устранена (wd+клип+гейт), но локальный кредит по времени встаёт на resid-полке при неконтрактивной петле — H-25 ✗ на дистанции 1500, открытая проблема C9 (⏸ ZoneRNN).
- [`experiments/EXP09_REPORT.md`](experiments/EXP09_REPORT.md) — **окно + амбразура памяти (M3, нога-2)**: носитель ZoneMLP-ctx32 обучается PC-M2 в воротах (+9.2% ppl к BP, работа 29%, шина ×19.5; H-26a ✓); эпизодический HDC-доступ за окно — по событию удивления: чтение 4% позиций → −2.5% ppl потока (+22.7% CE внутри маски), чужой корм −10.5%; H-26b уточнена.
- [`experiments/EXP11_REPORT.md`](experiments/EXP11_REPORT.md) — **перенос солвера (H-28, µTransfer AIra)**: найден закон «глубина связана с β» (T(β) 32→64, −2.8 п.п. на 800k, принят в спецификацию M2/M3 v3.1); честные ✗: T=64 при β=1 — яд (мелкий недорелакс регуляризует), наивные BP-якоря разрушительны (пила шкал), RMS-якоря нейтральны при 5% → послойная форма H-29c; наклон после лекарств +6.2 п.п./0.83 дек.
- [`experiments/EXP12_REPORT.md`](experiments/EXP12_REPORT.md) — **сильный солвер (M2.1, Андерсон)**: AA встроен в ядро со сторожем энергии; вердикт H-30 ✗ для обучения (96 +6.0% vs +5.06% чистыми; 512 +11.07% = чистые +11.3%), принят в арсенал точных режимов; вывод-кристалл: «жёсткость большой зоны» — болезнь фазы β=1, не зоны (resid 512@β=0.1 уже 0.028); честная асимптота @2400 вскрыла поздний дрейф (+7.8% от минимума) → H-31 (закон K2, финал lr-расписания) и EXP-13.
- [`experiments/EXP10_REPORT.md`](experiments/EXP10_REPORT.md) — **лестница масштаба (Правило S)**: зазор PC↔BP против ёмкости {117k,352k,800k} измерен: наклон +9–12 п.п. — риск C6 получил число за 15 минут стойки; β-затухание (H-28, µTransfer AIra) снимает позднюю регрессию и −6.3 п.п. на большой ёмкости; экономия (работа 18–42%, шина ×18–23) с ростом зоны держится.
- Запуск: `bash scripts/setup_env.sh` (AIRA_NO_TORCH=1 — без torch), затем `.venv/bin/python experiments/exp01_pc_trilemma.py` (и др. по отчётам).

## Ближайшие шаги

1. **M3 — языковой носитель**: нога-1 (ZoneRNN) ⏸ по C9 (рычаги: контрактивный Wh, линейная/SSM-петля, редкий BP-якорь); нога-2 построена (EXP-09, H-26) — далее: PC-контроль 1500 шагов, семантические ключи памяти уровня фраз (EXP-06-машинерия вместо char-16), KL-дрейф генераций 2k, сборка S0-LM (1–3M пар.) против GPT-стойки M1.
2. **Масштаб-перенос (H-28/H-29/H-31)**: законы K1 (T-β, EXP-11) приняты; M2.1 переосмыслен EXP-12 (корень — β-фаза, не предобусловливатель; Андерсон в арсенале ядра); далее — K2 финал lr-расписания (H-31, EXP-13: дрейф 512@2400), послойные BP-якоря (H-29c), лестница до 2–4M с валидацией законов.
3. Событийный рантайм вместо numpy-симулятора freeze (там экономия S3 становится реальной, не подсчётом).
4. Мелочи стойки: семплирование из обученной GPT-micro (чек-лист RIG_REPORT).
