# AIra

Исследовательская программа: **мозго-подобные алгоритмы для энергоэффективного ИИ**.
Цель — не «ещё один SOTA», а максимальное приближение к организации и энергоэффективности мозга средствами алгоритмов (событийность, локальное обучение, разрежение, множественные временны́е шкалы), с возможностью обучать и использовать модели на этом стеке.

## Документы

- [`research/ROADMAP.md`](research/ROADMAP.md) — миссия, граница «оптимизация vs новая система» (§0.2), mainstream-first стратегия (§1.1), тематическое дерево (T0–T14), этапы (P0–P7), метрики.
- [`research/LITERATURE.md`](research/LITERATURE.md) — глубокая аннотированная библиография по всем темам.
- [`research/THEORY.md`](research/THEORY.md) — **рабочая теоретическая статья** (v0.3): три асимметрии, теоремы событийной экономии, скетч-вещание ошибки, трилемма локального кредита (§11), зонная организация (§12), экспериментальная валидация (§11а).
- [`research/THEORY_OPEN.md`](research/THEORY_OPEN.md) — журнал потолков (C1–C8) и обходов + повестка дальнейшего думанья.
- [`research/HYPOTHESES.md`](research/HYPOTHESES.md) — журнал фальсифицируемых изобретательских гипотез (H-01…H-18).

## Код и эксперименты

- [`src/aira/`](src/aira/) — ядро: `pc.py` (равновесное обучение, солверы Richardson/Jacobi/зонный/Multigrid), `events.py` (σ-δ кодек), `energy.py` (энергопрокси).
- [`experiments/EXP01_REPORT.md`](experiments/EXP01_REPORT.md) — **трилемма локального кредита**: FF-11/FF-12 подтверждены [Э], H-14 ✓ (×16–23), H-18 ✓ (мультигрид, наклон 0,11 vs 2,00).
- [`experiments/EXP02_REPORT.md`](experiments/EXP02_REPORT.md) — **σ-δ событийное кодирование**: FF-1/FF-3 подтверждены, канал σ-δ даёт ×8–40 бит экономии.
- Запуск: `python3 -m venv .venv && .venv/bin/pip install -r requirements.txt`, затем `.venv/bin/python experiments/exp01_pc_trilemma.py`.

## Ближайшие шаги

1. **P0 — Метростойка**: энерго-прокси (SOP/MAC/трафик памяти), harness задач, графики Pareto точность↔энергия.
2. **P1 — Ядро событий**: компактный event-driven рантайм со спайковыми слоями (LIF / sigma-delta).
3. **P2 — Лаборатория локальных правил**: PEPITA/FF/SigProp/DFA/SoftHebb/PC/e-prop на едином интерфейсе с едиными метриками.
