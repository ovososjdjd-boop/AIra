# workspace

Личное рабочее пространство: все дела, идеи и проекты в одном репозитории,
разложенные по направлениям. Работаем здесь постоянно, без разделения на «сессии».

## Структура

| Папка | Что внутри |
|---|---|
| `_inbox/` | Входящие: сырые идеи, мысли, ссылки. Сначала сюда, потом раскладываем по местам |
| `science/` | Наука и исследования: заметки, статьи, эксперименты |
| `study/` | Учёба: конспекты, задачи, планы обучения |
| `personal/` | Личное: планы, списки, разборы жизненных вопросов |
| `projects/` | Проекты (код и не только): подпапка на каждый проект |

## Правила работы

1. **Новое — в `_inbox/`**. Появилась идея/тема — создаём файл в `_inbox/`
   с датой в имени (`2026-08-07-название.md`). Не думаем сразу, куда её —
   разберём потом.
2. **Работа — по направлениям**. Как только тема переросла заметку,
   переносим/развиваем в нужной папке. У проекта появляется своя подпапка
   в `projects/`.
3. **`DASHBOARD.md` — текущий срез**. Что сейчас активно, что на паузе,
   что ждёт ответа пользователя. Обновляем по ходу, чтобы в начале любого
   разговора за 30 секунд понять контекст.
4. **Без церемоний**. Формат внутри свободный; главное — дату и статус
   указывать, чтобы через месяц было понятно, что это было.

## Договорённости

- Имена файлов: латиница, даты в формате `YYYY-MM-DD`.
- Ничего не удаляем без спроса — старое помечается `архив` в статусе.
