# EXP-11 «Перенос солвера» — H-28 (µTransfer AIra): лечение 512-полки законами

**Дата:** 2026-08-06 · **Стойка:** M1 (sandbox-cpu-2core, numpy float32) · **Данные:** корпус M1 (char-64)
**Гипотеза:** H-28 · **Родитель:** EXP-10 (H-27 ✗, наклон +9–12 п.п.; медицинская цепочка начата β-затуханием)

---

## 1. Постановка

EXP-10 разложил болезнь наклона: переносимость замороженных гиперпараметров ✗; поздняя
регрессия β=const (вылечена); остаток — жёсткость релаксации больших зон (T̄=32 упёрт на всех
размерах). H-28: вместо повторной ручной подгонки — **законы переноса**: T(d) глубины,
квантильный сон, β(d,t)-затухание. Метод: сначала дешёвый триаж на прогретых весах (минуты),
затем полные прогоны концов лестницы.

## 2. S0 — диагностика полки (прогретые 512, β=1.0, протокол EXP-07 S1)

| T | общий cos | min-слой cos | resid |
|---|---|---|---|
| 8 | 0.532 | 0.427 | 0.751 |
| 16 | 0.349 | 0.911 | 0.767 |
| 32 | 0.490 | 0.891 | 0.526 |
| 64 | 0.653 | 0.815 | 0.370 |
| 96 | 0.774 | 0.839 | 0.133 |

Выводы: (а) полка — **итерационная, не фундаментальная**: resid падает с T (0.53→0.13),
cos растёт (0.49→0.77) — в отличие от ZoneRNN-полки EXP-08, где resid замирал; (б) при T=32
на 512 релакс недожат (stall-правило при resid>0.05 не срабатывает — всегда полный бюджет T);
(в) при отжатом β (конец затухания) жёсткость ниже — T̄ в реальном обучении мягче картины выше.
Закон K1-кандидат: **глубина T(d) растёт с размером зоны** (512 просит 64–96 при β=1).

## 3. S1 — фронтир сна на 512 (T=32, β=1.0)

| режим сна | cos | работа |
|---|---|---|
| абсолют 3e-3 | 0.424 | **0.123** |
| квантиль q0.5 | 0.414 | 0.508 |
| q0.7 | 0.362 | 0.311 |
| q0.8 | 0.385 | 0.213 |

Вывод: сон на 512 бесплатен при любом режиме (Δcos в шуме), но **абсолютный порог
доминирует фронтир** (та же точность при 0.123 работы против 0.31–0.51 у квантиля) — квантиль
не нужен на этой задаче; рост работы 0.18→0.42 в EXP-10 объясняется не порогом сна, а
самим состоянием PC-обучения (распределение градиентов в ходе PC-шагов). Квантильный закон
оставлен в арсенале как нормированный вариант для режимов, где абсолют сломается (другие
функции потерь/данные), но в спецификацию v3 идёт абсолютный порог с мониторингом.

## 4. S2 — спецификация v3: β→0.03 + T=64 + freeze 3e-3, концы лестницы @1200 — ОТРИЦАТЕЛЬНЫЙ

| конец | ppl PC | зазор к BP | работа | T̄ | ×шина |
|---|---|---|---|---|---|
| 96 | 1.1840 | +6.04% | 0.156 | 64 | ×38.3 |
| 512 | 1.4276 | **+24.8%** | 0.445 | 64 | ×40.3 |

Итог: наклон вырос до +18.8 п.п. — **спецификация v3 хуже рецепта c EXP-10** (T=32, β→0.1:
+5.06% / +14.1%). Кривая 512 честна до конца: 1.506@300 → 1.329@600 → **1.283@900 →
1.426@1200** — поздний срыв рядом с минимумом β. Разбор confounds (две переменные менялись
одновременно — ошибка дизайна, исправляется парой прогонов ниже):

- рабочая гипотеза-механизм: **глубина релаксации при сильном β — яд** (глубокий недорелакс
  вбирает β-смещение точнее; мелкий шум T=32 регуляризует — аналог SGD-шума; согласуется с
  96, где T=64 тоже не помог: +6.04% против +5.06%); следствие-конструкция: **глубина должна
  быть СВЯЗАНА с β**: мелко при сильном, глубоко при малом (T(β): 32→64 по ходу затухания);
- альтернатива: срыв вызван полом β=0.03 сам по себе (тогда v3 ни при чём).

Пара разделения (512, 1200 шагов): **v3c** T=32, β→0.03 (чистый эффект пола) и
**v3d** T(β): 32→64 связанная, β→0.1 (конструкция гипотезы). Результаты — §4b.

## 4b. Пара разделения confounds на 512 — механизм подтверждён, закон найден

| прогон 512 @1200 | ppl | зазор | итог |
|---|---|---|---|
| рецепт c EXP-10 (T=32, β→0.1) | 1.3048 | +14.1% | база лучшая до этого |
| спецификация v3 (T=64, β→0.03) | 1.4276 | +24.8% | ✗ поздний срыв 1.283→1.426 |
| **v3c** (T=32, β→0.03) | 1.3069 | +14.3% | без срыва ⇒ пол β=0.03 не при чём; **яд — T=64 при β=1-фазе** |
| **v3d** (T(β): 32→64 связанная, β→0.1) | **1.2729** | **+11.3%** | без срыва (1.303→1.270, ещё снижается) ⇒ **механизм верен**: глубина при малом β — не яд, а лекарство |

**Закон переноса K1 (принят в спецификацию M2/M3 v3.1): глубина релаксации T связана с β
(мелка при сильном подталкивании — не вбирать смещение; глубока при слабом — точный почти
несмещённый градиент).** Закон по построению переносим по размерам (привязка к расписанию β,
не к размеру зоны) — это и есть требуемая форма законов H-28. Типичная цена: T̄=48 против 32.

Серия после закона: наклон 96→512 = +5.06% → +11.3% = **+6.2 п.п.** (ворота +5 — погранично
в шуме протокола ±1 п.п.). Остаток наклона адресуется страховкой C6 — §5.

## 5. C6-страховка: редкие BP-якоря — наивно ✗, механизм найден, RMS-форма 🔬

**Наивная постановка ✗ (измерено, фиксируем):** каждый 20-й шаг — точный BP-градиент
(бюджет 5%) в общий AdamW → 512: ppl 1.8922 (**+65.4%**, расползается к концу: 1.68→1.76→1.84),
96: 1.5380 (+37.7%). Механизм разрушения: шкалы PC- и BP-градиентов по массивам различаются
систематически (у PC голова ∝β·CE, внутренние веса ∝ локальным ошибкам предсказания; у BP —
сквозная развёртка CE), общий адаптивный оптимизатор получает пилу эффективного шага по v̂:
редкие крупные BP-спайки на фоне мелких PC-градиентов дают гигантские шаги (пила), ход ломается —
**это тот же класс болезни, что σ-δ разнос θ=0.15 в EXP-02: смешение шкал убивает**.
Вывод для доктрины C6: якорь не может быть «подменой шага», только **масштаб-согласованной
коррекцией**.

**RMS-форма (измерено): нейтральна при бюджете 5%.** 512: ppl 1.3069 (+14.3% — статистически
ровно чистый рецепт c, +14.1%, и ХУЖЕ закона T(β) §4b, +11.3%); 96: 1.1836 (+6.0% против
чистых +5.06%). Разрушение устранено (траектории гладкие), но 5% бюджета глобальности серии
не закрывает: якорное направление не несёт информации, которой траектории PC не хватает,
на этих размерах. Статус страховки C6: **не доказана в наивной и RMS-форме**; следующая
форма в очереди — послойная (якорить только худший по косинусу слой, S0/S1 показывают,
что min-слой ~0.81–0.91 — концентрация бюджета туда, где релакс отстаёт).

## 6. Вердикт H-28 и законы, принятые в спецификацию M2/M3 v3.1

**H-28 (первая серия): частичный ✓ с честными ✗.** Найден и подтверждён механизм-закон **K1:
глубина релаксации связана с β** (мелка при сильном β — не вбирать смещение; глубока при слабом
— точный градиент; −2.8 п.п. на большой зоне, по построению переносим по размерам). Отрицательные
результаты зафиксированы полностью: глубина фиксированная T=64 при β=1 — яд (поздний срыв);
наивные BP-якоря — разрушительны (пила шкал); RMS-якоря 5% — нейтральны. Наклон лестницы после
всех лекарств: +5.06% → +11.3% = **+6.2 п.п.** (погранично воротам +5 п.п. в шуме ±1 п.п.).
Событийная ось: работа 0.18–0.45, шина ×18–40 — держится во всех формах.

**Спецификация M2/M3 v3.1 (действующая):** однофазный PC, β: 1.0→0.1 линейно по шагам;
T(β): 32→64 связанная линейно; BB+сторож; freeze абс 3e-3; шина θ=0.05; wd=0.01.
Долги, повышенные в приоритете: M2.1 сильный предобусловливатель (resid<0.01 — остаточный
источник наклона); послойные якоря как форма C6-страховки (только худший слой, K мелкий).
