## §0. Постановка: три асимметрии вместо «сходства с мозгом»

«Эффективность мозга» не сводится к биохимии. Сравнение двух вычислительных моделей показывает три формальные асимметрии, из которых всё следует:

| | Современный ИИ (фон-неймановская модель нейросети) | Мозг (и наш целевой субстрат) |
|---|---|---|
| **Асимметрия 1 (событие/такт)** | каждый вызов — полная оценка всех P параметров | работа только там и тогда, где произошло событие |
| **Асимметрия 2 (функция/система)** | ответ вычисляется заново из входа: y = f(x) | ответ уже «досчитан» в состоянии: y = g(s), s дообновляется |
| **Асимметрия 3 (глобальное/локальное)** | обучение = транспорт градиента по графу (backprop) | обучение = локальное следствие локальных событий + широковещательный модулятор |

Замечаем: энергетический разрыв (§1–§2) исходит из асимметрии 1; скоростной и латентный — из асимметрии 2; обучающий (главный научный риск) — из асимметрии 3. Дальнейшее — попытка превратить каждую асимметрию в теорему, а встретившиеся потолки честно зафиксировать и обойти (журнал потолков — `THEORY_OPEN.md`).

## §1. Теорема событийной экономии (стоимость ∝ изменениям, не размеру)

**Конструкция.** Канал сигма-дельта: источник x(t) держит реплику приёмника x̂; в момент |x(t) − x̂| > θ источник посылает значение и обновляет x̂ ← x(t). Между событиями приёмник ничего не делает.

**Лемма (граница работы).** Пусть x на [0,T] имеет полную вариацию V_T = ∫₀ᵀ|ẋ|dt. Тогда число событий n ≤ V_T/θ + 1, а ошибка воспроизведения |x − x̂| ≤ θ в любой момент.

*Доказательство.* Между двумя событиями t_k, t_{k+1}: |x(t_{k+1}) − x(t_k)| > θ, значит вклад этого интервала в вариацию ≥ θ. Суммируя: V_T ≥ (n−1)θ. Неравенство ошибки — из правила обновления. ∎

**Следствие (асимметрия 1 количественно).** Для многомерного сигнала x ∈ ℝ^N с поканальной вариацией V_i: работа W ≤ Σ_i V_i/θ. Для входов, у которых большинство каналов почти не меняются (типично для сенсорики и для активаций глубоких сетей при генерации), W ≪ N·(число шагов). Плотная сеть платит N·(шаги) независимо от V. То есть **коэффициент выигрыша событийной модели = N·D / ΣV_i·θ⁻¹ = обратная «средняя информативная скорость изменения на канал»** — величина, меральная на реальных данных (эксперимент H-02).

*Замечание.* Это та же математика, что у событийных камер (DVS) и дельта-кодирования; новизна для нас — применение к *внутренним* активациям сети как универсальному слою «событийности».

## §2. Оптимальность разрежённых событий в битах на джоуль

**[Ф, Verdú 1990; Levy & Calvert 2021].** Для канала, где символ «0» бесплатен, а символ «1» стоит c, пропускная способность в единицах **бит/энергия** растёт при p(1) → 0: (двоичная энтропия)/c·p = h(p)/(c·p) ~ ln(1/p)/c → неограниченно растёт по мере разрежения. Физический смысл: на фиксированный энергобюджет информационно выгоднее редкие сильные события, чем частые слабые. Это не эвристика — это свойство канала с асимметричной ценой символов.

**Вывод для субстрата.** Проектная норма активности: средняя доля активных синапсов/киналов ρ ~ 10⁻²–10⁻³ (как у коры: средняя частота спайков 0,1–2 Гц при τ_события ~мс). Норма не «экономности ради», а информационно-энергетического оптимума. Практическое правило дизайна: любая регуляризация/гомеостатика в субстрате должна удерживать ρ в этом окне, а штраф в функционале — за *энергию*, не за «среднюю активацию».

## §3. Амортизированное вычисление: от функции к динамической системе (устойчивость пороговых обновлений)

**Проблема.** Transform-подход вычисляет y_t = f(x_1..x_t) заново на каждом шаге — «повторный налог на всё уже посчитанное». Динамический подход: s_t = F(s_{t−1}, x_t), y_t = g(s_t): большая часть ответа уже находится в состоянии, работа = дообновление.

**Страх: можно ли «догадаться» обновлять состояние только по значимым изменениям, не ракручивая ошибку?** Отвечает следующая лемма.

**Лемма (ограниченный дрейф при пороговом обновлении, [В]).** Пусть идеальная динамика сжимающа: s_t = A s_{t−1} + B x_t, ||A|| ≤ λ < 1. Пороговое правило: обновлять оценку ŝ только когда ост из неточного следования > θ, иначе заморозить. Тогда ошибка e_t = s_t − ŝ_t удовлетворяет e_{t+1} ≤ λ e_t + θ, и потолок ошибки: lim sup e_t ≤ θ/(1−λ).

*Доказательство.* Между обновлениями ошибка сжимается со скоростью λ (обе траектории подчиняются одному A); каждый пропущенный апдейт добавляет ≤ θ. Индукция по времени обновления даёт геометрическую границу. ∎

**Смысл.** Сжимающая динамика *прощает* пропущенные обновления: дрейф ограничен константой θ/(1−λ), а не растёт во времени. Условие применимости: распространённые в глубоком обучении механизмы (нормализация, остаточные связи с малыми выигрышами, gate'ы) уже делают слойные операторы слабо сжимающими или нейтральными; жёсткий отказ от «честного рекуррентного обновления» каждый шаг выдерживается точность при малых θ. — Это точная математическая база под H-02 (σ-δ внутри декодирования LLM) и под весь рекуррентный дизайн AIra-0.

**Открытый момент (честно).** Составные системы со слоёных цепей глубины L дают e ≤ Lθ/(1−λ) при независимых ошибках — линейный рост по глубине, значит θ должно масштабироваться как 1/L или блочное обновление должно синхронизироваться (см. потолок C3 в THEORY_OPEN).

## §4. Обучение без глобального транспорта: формализация и «семейство равновесных правил»

**Задача.** Разрешённые вычисления обновления: Δw_ij = F(pre_i, post_j, сигналы, доступные широковещательно). Цель: направленное улучшение функционала L(w) на данных/потоке.

**Вывод трёхфакторной формы (как e-prop получается из градиента).** Для рекуррентной сети h_t = φ(Ah_{t−1} + Wx_t):

```
∂L/∂W = Σ_t δ_t · ∂h_t/∂W,     ∂h_t/∂W = φ'_t x_{t} + A·∂h_{t−1}/∂W   (RTRL-рекурсия)
```

e-prop-приближение: удерживаем только локальное слагаемое рекурсии — eligibility-след e_t = φ'_t ⊗ x_t (диагональное приближение Якобиана + след), усечённый по горизонту K ~ 1/(1−λ_A). Ошибка усечения градиента — сумма членов порядка λ^K·‖∂δ‖ — мала при сжимающей рекуррентности. Итоговое правило: **Δw_ij = η · M_j(t) · e_ij(t)** — третий фактор M (где M — широковещательный вектор ошибки/удивления, общий для большой популяции).

**Систематизация [В, немного нестандартная]: всё зоопарк биоправил — одно семейство.** Предиктив-кодинг, equilibrium propagation, contrastive-Hebbian/GeneRec, Forward-Forward — это **равновесное обучение**:

```
Локальное правило ≡ Энергия E(s,z;y,w)  +  динамика релаксации s → s*  +  Δw = −η·∂E/∂w |_{s*}
```

PC получается при квадратичной E по ошибкам слоёв (равновесие ≈ backprop-градиент в пределе [Ф: Song+ 2020, Whittington–Bogacz 2017]); EqP — при энергетической функции Хопфилда с фазами free/nudged; FF — при E = ±goodness с контрастивными (x,y) и (x,ỹ). Обновление Δw локально, потому что ∂E/∂w_ij включает только s_i*, s_j*.

**Из этого следует исследовательская программа сужения пространства:** вместо перебора эвристик — конструктивный поиск по *энергиям*, у которых (а) равновесие дёшево достижимо событийной динамикой (§1), (б) ∂E/∂w в равновесии несёт максимум информации о глобальной цели на единицу требуемого широковещания (§5). Формулировка Γ-задачи: найти E минимизирующую (широковещательный бюджет k)·(глубина L)·(шаги до равновесия T_rel) при фиксированном качестве обучения.

## §5. Потолок транспорта ошибки: скетч-бюджет «нейромодулятора» (считаем честно)

Проблема, в которую упирается вся асимметрия 3: скарярный/малый broadcast не может нести полный вектор ошибки δ ∈ ℝ^d. Допустим скетч Через случайную проекцию R ∈ {±1/√k}^{k×d} (лемма Джонсона–Линденштраусса: k = O(ε⁻² ln n_L) сохраняет попарные скалярные произведения до ±ε). Оценка градиента: δ̂ = RᵀRδ / k. Тогда:

```
E[δ̂] = δ;      E‖δ̂ − δ‖² ≈ (d/k)·‖δ‖²        [В, стандартный дисперсионный подсчёт]
```

**Числа.** d = 10⁶, k = 10³: относительное СКО от одного скетча ≈ √(d/k) ≈ 31 — **одиночный скетч бесполезен**. Лечение усреднением S независимых скетчей (у eligibility-следов оно встроено — следы и есть аккумуляторы по времени): требуемое S для выравнивания cos(δ̂, δ) ≥ γ:

```
S ≥ (d/k)·(1−γ²)/(γ²)      [В]
γ = 0,3, k = 10³, d = 10⁶  →  S ≈ 10⁴ событий на значимое обновление
```

10⁴ событий на апдейт — это ~секунды живого потока: **подтверждение, что мало-канальный модулятор совместим с обучением, только если время-интегрирование стоит в самом правиле (что мозг и делает eligibility-трейсами)**. Это не поражение, а эквислиционная связь между «канальностью модулятора» и «временем интеграции» — количественная рамка H-01/H-09.

**Три обхода потолка (подробнее — THEORY_OPEN):**
1. **Иерархический модулятор** (дерево вещания, дендритная/ламинарная структура коры): разбиение популяции на блоки скоростей модуляции — дисперсия на синапс масштабируется размером блока, а не полной d. Конструктивный вариант: k каналов верхнего уровня + b локальных каналов на блок.
2. **Эмерджентное выравнивание** [Ф: feedback/direct-feedback alignment]: при фиксированной, но произвольной матрице обратной проекции прямые веса поворачиваются в её подпространство в ходе обучения (выравнивание силы «знаковой симметрии») — шум скетча частично компенсируется адаптацией сети. Не объясняет инициализацию траектории, но микширует позднюю фазу.
3. **Кодовое разделение каналов** (CDMA-подобие): k «нейромодуляторов» как ортогональные коды — подканалов k·log раз больше, синапс «подписан» на свой код (структурная проекция) — то есть проекция не случайная, а заданная топологией. Связывается с Zador-приорами (§LITERATURE, T10): «схема вещания» может быть наследуемой структурой.

**Строгий нижний предел (чему верить).** Независимо от схемы, эффективная роль модулятора — не «воспроизвести градиент», а **сообщать знак/ранг локального улучшения**: для оси «становится лучше/хуже» достаточно cos > 0 с небольшим перевесом — обучение в стиле стохастической аппроксимации сходится и при очень шумных уклонах, если матожидание уклона имеет положительную проекцию на истинный градиент (условие Роббинса–Монро на суммы η_t). Вот почему выравнивание 0,1–0,3 уже работоспособно — вопрос в цене по времени.

## §6. Сходимость «живого» субстрата и вывод гомеостаза из двойственности

**Проблема.** Если веса никогда не замирают (нет фазы «обучили — пользуемся»), сходится ли система вообще?

**Якорь [Ф, Боркар, двувременовая стохастическая аппроксимация].** Система с быстрыми переменными u(t) (состояния) и медленными w(t) (веса), с шагами η_u ≫ η_w и b_n/a_n → 0, при устойчивости быстрой подсистемы сходится п.н. к (u*(w*), w*) — локальному решению предельного ОДУ. Применение: наш субстрат — легальный объект этой теории при разнесённых шкалах: мембрана (мс), следы (с), веса (мин–часы), метапластичность (часы–дни). **Гипотеза H-10: стабильное плато наступает при отношении шагов пластичности к темпу состояния ≤ 10⁻²** — проверяется измерением, и это даёт проектную константу всего стек-кэйка шкал.

**Гомеостаз — из Лагранжа [В].** Требуем: удерживать среднюю активность и т.п. ограничения. Максимизируем качество L при ограничениях E[r_i] = r* (цяль по частоте). Лагранжиан: L − Σ μ_i(E[r_i] − r*). Двойственный апдейт: dμ_i ∝ (r_i − r*). Это **в точности правило внутренней пластичности/ISP** (адаптация порогов по избытку/дефициту частоты). То есть гомеостатика — не «патч стабильности», а двойственные переменные ограниченной задачи, и метапластичность — двойственные переменные второго эшелона. Получили единый синтаксис: пластичность = primal, метапластичность = dual.

## §7. Долгая память: каскад Фузи и конверт памяти

Катастрофическое забывание = экспоненциальный распад следов при перезаписи. Каскад сложного синапса [Ф: Fusi+ 2005; Benna & Fusi 2016]: у веса есть K внутренних метапластичных состояний; вероятность перехода глубже мала. Распад памяти перестаёт быть экспонентой и становится ≈ t^{−1/2} (диффузионная картина в цепочке состояний); время жизни одного воспоминания в N таких синапсах ~ √N (конверт памяти — против ~постоянной у простых весов).

**Проектное решение [Г]:** каждый синапс — не скаляр w, а кортеж (w, m₁..m_K), глубина продвижения по каскаду ∝ интегральной «важности» |Σ M·z| — измеримо локально; при «сне» (§8) стимулируется продвижение без затирания содержимого. Это честный кандидат на локальную реализацию continual learning без буфера данных (H-07, H-11).

**Свободный параметр:** глубина каскада K платится битами состояния на синапс; при K=4–8 (экономично) прогнозируемый переход экспонента→t^{−1/2} измерим в течение ~10³ событий обновления (предсказание H-11).

## §8. Реплей как умножитель данных (прикидываем предел)

Реплей: оффлайн-генерация выборок из собственной динамики модели + обучение на них. Пусть генеративное распределение p̂ отличается от истинного p по W₁-расстоянию. Для липшицевой потери |E_p[l] − E_{p̂}[l]| ≤ Lip·W₁(p,p̂) — обучение на реплеях стоит нам W₁-ошибку при нулевой цене данных. До тех пор, пока W₁ мала (факты ещё «свежи» в весах), **реплей умножает выборку почти бесплатно». Мозг использует это (гиппокампальный реплей), и цена для него — только энергия самодинамики, низкая при событийной экономии §1.

**Количественная оценка [В]:** выигрыш sample-efficiency ≈ (1 + R) с потолком, где R — доля реплеев, при которой W₁·Lip остаётся ≲ допуска обучения. На практике множитель порядка ×3–10 до заметной деградации — то есть **реплей покрывает значительную часть разрыва D из §3 ENERGY_MODEL**; остаток закрывают приоры структуры (Zador) и эпизодическая память (H-05).

## §9. Полная спецификация субстрата AIra-v0 [Г, инженерная формула]

```
Юнит i: две каморки: базальная v_i (прямой поток), апикальная μ_i (модулятор/ошибка)
Событие: s_i(t) = 1, если v_i > θ_i, иначе 0; θ_i подстраивается ISP (§6)
Связность: v_i ← Σ_j w_ij·s_j(t−d_ij)   (задержки d_ij — обучаемый ресурс, см. lit: delay-learning)
Следы: z_ij ← λz·z_ij + nonlin'(v_i)·s_j            (быстрые, сек)
       ẑ_ij ← λẑ·ẑ_ij + M_i·z_ij                    (медленные, часы; накопитель «важности»)
Правило: Δw_ij = η_w·[M_i(t)·z_ij] − decay(w, cascade)      (локальное, без backward-графа)
Каскад: продвижение вглубь состояний при |ẑ_ij| > θ_p       (§7)
Модулятор: M(t) — k-мерный бродкаст-скетч глобального удивления/ошибки (§5), обновл. по блокам
Фазы: wake = онлайн-поток с правилами выше; sleep = генеративная самодинамика + каскад-продвижение (§8, §7)
Гомеостаз: μ-подобные двойственные переменные удерживают ρ в окне 10⁻²–10⁻³ (§2, §6)
```

Свойства по построению: (а) стоимость шага ∝ числу событий × fanout + числу синапсов с событием пластичности (§10); (б) нет autograd-графа, нет хранимых активаций — есть следы O(P) локальных переменных + O(k) бродкаста; (в) обучение = инференс на разных шкалах (Боркар-конвергенция при разнесении η, §6).

## §10. Ценовая модель и честный эмуляционный налог

**Нативная стоимость субстрата** (на идеальном событийном исполнителе, Loihi-класс):
```
Энергия(Δt) ≈ (n_событий · f̄) · e_SOP  +  n_plast · e_upd  +  Uтечка
n_событий = ρ·N·Δt,  f̄ — средний fanout
```
При ρ=10⁻², f̄=10³, N=10⁸ «нейронов»: 10¹² SOP/с… корректировка: ρ на синапс ниже; практическая оценка Loihi-подобных систем — единицы–десятки пДж/SOP → десятки мВт–Вт на потоковой нагрузке против сотен ватт GPU на той же — отсюда опубликованные ×10²–10³ на cache-aligned задачах [Ф, см. lit].

**Эмуляционный налог на GPU [В].** Плотный загрузчик вместо событий платит P·b·e_mem за шаг; идеальная событийная оплата: ρ·N·f̄·e_eff. Отношение ≈ (P·b·e_mem)/(ρN f̄ e_eff). Для P=10⁹, b=2Б, ρ=10⁻², f̄=10²: налог ~ 10²–10³ — эмуляция на плотном железе «съедает» нативное преимущество, если исполнять лобово. **Обход (Г, H-12): блочная событийность** — вычислять только блоки с событием; гранулярность блока = векторной ширине железа (SIMD/warp 32–128): сохраняется ~90% событийной экономии при плотной арифметике внутри блока. Вывод предельной формулы: оптимальный размер блока g* = argmin_g [g·(1−(1−ρ)^g)·e_dense/g + overhead(g)] — измеряемая функция от ρ и ширины вектора, предсказание минимума при g* ≈ ln(1/α)/ρ для малых ρ (порядка сотен при ρ=10⁻²).

## §11. Конструктивный класс энергий с нулевым дальним бродкастом и трилемма локального кредита (задача N2, серия 1)

Γ-задача §4: найти E с малым (бродкаст k)·(глубина L)·(время релаксации T_rel) при фиксированном качестве. Результат цикла: класс-кандидат найден, его **дальний бродкаст равен нулю строго**, но внутри класса обнаружилась точная трилемма «локальность–скорость–точность» — она и есть следующий потолок (обострение C6).

**Класс энергий** (блочно-квадратичные с соседними связями):

```
E(s; w, y) = Σ_l ½‖ε_l‖²_{Π_l}  +  β·ℓ(s_L; y),     ε_l = s_l − W_l·φ(s_{l−1})
```

Π_l ≻ 0 — (диагональные) матрицы точности. Релаксация: градиентный поток ṡ = −∂E/∂s; обучение в равновесии: **ΔW_l = η·Π_l·ε_l·φ(s_{l−1})ᵀ** — произведение постсинаптического остатка на предсинаптическую активность; ни одного несоседнего сигнала не требуется [В].

**Предел точности подтверждён в литературе в сильной форме [Ф]:** в равновесии остатки этого класса равны backprop-дельтам, сходимость к ним экспоненциальная, класс покрывает произвольные графы вычислений (CNN/RNN/LSTM), а не только цепочки слоёв (Millidge–Tschantz–Buckley, Neural Computation 2022; восходит к Song+ 2020, Whittington–Bogacz 2017). Т.е. Γ-задача имеет конструктивное решение с нулевым дальним бродкастом: вся нелокальность платится **временем**, а не полосой.

**Цена локальности: диффузия кредита [В, вывод цикла].** Линеаризация динамики остатков у равновесия: ė = −Mε, где M = I − T, T — блочная бидиагональ межслойного переноса. Две крайности:

```
(a) ‖T‖ ≤ α < 1        ⇒  зазор λ_min(M) ≥ 1−α,  T_rel ~ log(1/ε_tol)/(1−α)  — быстро,
    но кредит в глубину затухает как α^k (точная форма потолка C6 внутри класса);
(b) перенос без потерь (α→1, точный BP) ⇒ M → лапласиан цепочки,
    λ_min = 2(1−cos(π/L)) ≈ π²/L²  ⇒  T_rel = O(L²·log(1/ε_tol)) — диффузионно медленно
```

**Трилемма (FF-12).** На цепочной глубине нельзя одновременно: (а) дальность сообщений = 1 (локальность), (б) быструю релаксацию, (в) незатухающий дальний кредит. Любая пара покупается, третье — нет. BP берёт (б)+(в) ценой (а); DFA/скетч (§5) берёт (а)+(б) ценой (в); точный PC берёт (а)+(в) ценой (б).

**Энергосчёт цены времени на GPU [В-оценка, новый].** Итерация релаксации читает веса W: пусть p — число проходов по W за итерацию (1–2). Транспорт весов на обучающий шаг: PC ≈ (p·T_rel + 1)·байт(W) против 2·байт(W) у BP (fwd+bwd). Лобовой налог ≈ (p·T_rel+1)/2 — наивный PC на GPU **дороже** BP (анти-результат, фиксируем). **Нейтрализация зонностью** (мост к §12): если веса зоны живут в SRAM-ярусе (e_SRAM ≈ 3 пДж/Б vs e_HBM ≈ 15), баланс p·T_rel·3 + 15 ≈ 2·15 ⇒ **безналогово при p·T_rel ≲ 5**, допустимо при ≲ 10. Выводы: (i) релаксация должна быть мелкой — внутризонная глубина L_zone мала (2–4 подслоя), T_rel = O(L_zone²) ≈ 4–16: именно это означает «зона» конструктивно; (ii) межзонный кредит идёт по другому бюджету — скетч/DFA-подобный по шине (§5), где затухание α^k уже некритично (бюджет точности кредита на магистралях сознательно ниже); (iii) предобуславливатель — не косметика, а условие энергетической безналоговости.

**Учёт бюджета глобальности (начало формализации N6).** Мера G = бит, пересекающих границы зон, на синаптический апдейт (на «слой=зона»):

| Правило | G, бит/апдейт | дальность | цена точного кредита |
|---|---|---|---|
| BP | O(активации графа): каждая участвует в δ ниже | O(L) хопов | O(L) последовательных шагов |
| PC точный (здесь) | 0 дальних; 2 локальных сообщения/синапс/итерацию | 1 | O(L²·log 1/ε) релаксации |
| DFA | k из головы всем слоям | звезда ∞ | O(1) время; качество cos — N4 |
| Скетч+e-prop (§5) | k бродкаст | звезда ∞ | S ≳ (d/k)(1−γ²)/γ² событий интеграции |

**Обходы трилеммы в порядке предпочтения:**
1. **Иерархический перенос — «мультигрид» [Г → H-18].** O(L²) — эпифеномен плоской топологии. Дальний скелет малого диаметра (log-иерархия шин, §12 Т4) переносит грубый кредит за O(polylog L), зоны уточняют локально. Гипотеза цикла: рост собственных времян коры вдоль иерархии ([Ф: Murray+ 2014]) и rich-club-скелет — это и есть мозговой мультигрид релаксации кредита/интеграции. Проверяемо дословно: T_rel PC-сети с/без иерархии шкал при фиксированной целевой точности.
2. **Событийная релаксация (σ-δ поверх ε, по §1) [В]:** переносятся только Δε > θ: асимптотика T_rel не улучшается, но энергия/итерация ∝ вариации остатков — и это ровно межзонный протокол мозга (§12 F4).
3. **Обучаемая диагональная точность Π_l (взвешенный Якоби):** дизайн Π под максимум зазора при лимите затухания — конструктивное ядро N2 серии 2 (повестка).

Экспериментальная цепочка: H-14 (T_rel и cos предобусловленной зоны), H-15 (энергия зонного PC vs BP в ваттах), H-18 (иерархия шкал), H-16/H-17 (шина и гейт из §12).

## §12. Зонная организация мозга: как делятся центры, чем общаются зоны, и перенос на субстрат

*(Повод: вопрос пользователя 2026-08-05 — «как мозг делит зоны ответственности, как они общаются и стоит ли это реализовать». Ответ цикла: реализовать, и это не украшение, а выведенная необходимость §11 — локальное обучение без энергоналога существует только при зонах размером с ярус памяти.)*

**F1. Сколько зон и как проведено [Ф].** Кора — ~10² областей на полушарие (парцелляция Glasser+ 2016: ≈180). Дальние проекции физически очень разрежены (подсчёт абсолютного числа аксонов белого вещества, PLOS Biol 2022), а доля нейронов с миелиновыми аксонами падает с ростом мозга как ~N^{−0.16} (Herculano-Houzel+ PNAS 2010): **чем больше система — тем меньше глобальность** (защита от N²-проводки).

**F2. Проводка не минимальна — избыток длины покупает интеграцию [Ф].** Строгая оптимизация размещения зон (Cherniak 1994) опровергнута: реальный коннектом длиннее минимального, но с короткими путями (Kaiser–Hilgetag 2006; человек: Network Neurosci 2023). Экономическая рамка (Bullmore–Sporns 2012): минимизация стоимости проводки ↔ польза топологии.

**F3. Дорогой скелет [Ф].** Rich club (~дюжина хабов): межхабовые связи несут ~40% суммарной стоимости трафика, ~69% кратчайших путей проходят через скелет; мотив пути: локально → аплинк → скелет → даунлинк → локально (van den Heuvel–Sporns PNAS 2012). Это структурное воплощение обхода #1 §11: граф малого диаметра для переноса, плотные модули для вычисления.

**F4. Протокол межзонной связи [Ф].** (а) **Окна связи**: когерентность осцилляций открывает эффективное окно передачи (communication-through-coherence, Fries 2005/2015) — маршрутизация реконфигурируется фазами без перекоммутации проводки; (б) **асимметрия потоков**: вверх идут **остатки** — непредсказанное, гамма 40–90 Гц, поверхностные слои; вниз — **предсказания**, альфа/бета 8–30 Гц, глубокие слои (Bastos+ Neuron 2012; «predictive routing» PNAS 2020). Предсказанное подавляется и не передаётся вообще: межзонный трафик мозга = σ-δ кодирование §1 на уровне зон (плата только за новизну), а низкочастотность обратного потока = мало событий = дёшево (§2); (в) **такты и сбросы**: медленные ритмы (тета 4–8 Гц) нарезают выборку и периодически разрывают синхронию — биологический прецедент встроенной частоты сбросов (обход 2 потолка C3).

**F5. Центральный гейт-маршрутизатор [Ф].** Таламус — не реле, а коммутатор: core-клетки — точечные каналы в средние слои, matrix-клетки — диффузные проекции в слой I, синхронизирующие/модуляторные (Jones 1998/2001); таламус высшего порядка (пульвинар) управляет межзонной связностью по вниманию — гейтит то, чего прямые связи не умеют (Sherman–Usrey 2024). Физически малый (вся подкорка <1% нейронов коры), но это отдельный **управляющий слой маршрутизации**.

**F6. Редкий глобальный флаш [Ф].** Глобальное рабочее пространство (Dehaene–Changeux): базовый режим — инкапсулированная модульная обработка; редкие «зажигания» (сигнатура P3b ~300 мс, гамма-всплеск) вещают контент всем процессорам через длинноаксонную фронто-париетальную сеть. Бродкаст — событие, не среда. Оговорка строгости: состязательная проверка COGITATE (Nature 2025) подтвердила зажигание по onset частично, по offset — почти нет, и PFC-декодирование слабее предсказанного; нам нужен не механизм сознания, а архитектурный инвариант «модульность + редкий полный флаш», который COGITATE не задевает.

**Перенос на субстрат — апдейт спецификации (AIra-v0.1, зонная редакция):**

- **Т1. Зона = граница яруса памяти.** Единица организации — весовая зона, целиком живущая в очередном кэше. Эскиз под H100-класс: SMEM-зона ~10⁵–10⁶ 2-бит весов (SMEM 228 КБ/SM); L2-надзона ~10⁷–10⁸ (L2 ≈ 50 МБ); HBM — остальная модель. Внутри зоны — мелкая (2–4 подслоя) предобусловленная релаксация §11 почти без транспорта.
- **Т2. Межзонная шина — σ-δ событийная (прямое следствие §1 + F4б).** Передаются только остатки/изменения выше порога θ_bus. Асимметрия: вверх — редкие «остатки-новизна» на высокой частоте, вниз — медленный поток предсказаний/порогов/гейтов на низкой (дёшев по §2 через счёт событий).
- **Т3. Пакетирование окон (CTC → GPU) [Г-соответствие, FF-17].** Мозг агрегирует события в когерентные пачки, чтобы дорогая передача шла в короткие окна с максимальной плотностью — структурный аналог блочной событийности §10 (тот же принцип, что коалесинг). Согласование порядков: зона 10³–10⁵ элементов при вероятности события 2–10% за 20-мс окно даёт пачки ~ десятки–сотни ≈ g* из §10. В субстрате: межзонные обмены группируются в микро-пакеты фиксированного окна.
- **Т4. Иерархия шин — «скелет» с экспоненциально падающим бюджетом.** Внутризонная → локальная межзонная → корневая. Подъём по ярусу подорожает битом, поэтому корень несёт только k-мерные скетчи (§5) и флашы (Т6). Тот же скелет — носитель мультигрид-переноса кредита (§11, обход 1 → H-18): бюджет точности кредита сознательно падает от шины к магистрали (мелкий кредит точный, дальний — ранговый).
- **Т5. Гейт-маршрутизатор (таламус-аналог) [Г → H-17].** Малый обучаемый управляющий слой на шине: ворота межзонных каналов, открываемые модулятором M(t); сам обучается локальным правилом; физически — разреженная матрица ворот, не полносвязность.
- **Т6. Редкий глобальный флаш.** Контент, прошедший порог глобальной важности, вещается всем зонам однократно; флаш — для консолидации/сна и исключительных событий, не носитель рядового кредита. Бюджет эскиза: ≤1 флаш на 10²–10³ шагов (порядок «зажиганий» ~раз в секунды поведенческого времени при ~мс шаге субстрата).

**Что это меняет в карте потолков.** C1 получает 4-й обход (зонная σ-δ шина + гейт); C3 — биологический прецедент сбросов (F4в); C6 переформулирован как точная трилемма (FF-12) с тремя «покупаемыми отказами» вместо одной непроходимой стены; N1 и размер зоны слиты в одну задачу (N8); C5 не тронут.
