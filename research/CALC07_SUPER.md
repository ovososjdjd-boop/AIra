## A. Измеренный закон duty(N): масштаб данных в одиночку — МЁРТВАЯ дорога

Семь опор (та же стенд-схема CALC-03b, char c8, правило 2D θ=0.90, N≥2),
счётчики переобучены на подвыборках train {1/64 … 1}:

| train, ток | duty@acc≥0.95 | acc |
|---|---|---|
| 32 372 | 5.9–11.5% | 0.903–0.951 |
| 64 745 | 8.9–14.9% | 0.919–0.954 |
| 129 489 | 12.7–19.2% | 0.930–0.959 |
| 258 979 | 16.7–23.5% | 0.936–0.960 |
| 517 958 | 21.1–27.5% | 0.944–0.963 |
| 1 035 916 | 28.7–31.2% | 0.950–0.954 |
| 2 071 833 | **34.3%** | **0.9566** |

Контроль: duty(полный train) = 34.32% @ 0.9566 — **бит-в-бит совпал с CALC-03b** ✓.

Фит хвоста: **1 − duty = c·N^(−γ)**, брекет по двум честным вариантам:
каноническое правило (θ=0.90, N≥2): γ = 0.073 (подокна 0.071–0.074);
строгий фит только по точкам с acc≥0.95: **γ = 0.086**.
Обе модели сходятся в прогнозе ближней ступени (Kaggle ×30: duty ≈ 49%),
расходятся вдаль — честный брекет и есть таблица ниже.

| Цель | Требуется токенов (брекет фитов) | Во сколько раз больше всего корпуса Opus-класса (1.3e13) |
|---|---|---|
| s = 0.90 (оптимист CALC-06) | **9.5e15 … 2.5e17** | **×730 … 48 000** |
| s = 0.95 | **3.0e19 … 3.1e21** | ×2 300 … 240 000 |
| s = 0.98 | ещё на 2 декады выше | — |

Даже по самому доброму фиту (γ=0.086) до оптимиста CALC-06 нужно в **730 раз**
больше текста, чем весь гипотетический датасет Opus-класса.

**Вывод-кристалл №1:** сверхрезультат НЕЛЬЗЯ купить данными. Закон Ципфа
держит хвост невиданного; экспонента 0.073 даёт лишь +5 п.п. покрытия за ×30
объёма. Единственная дверь — **обобщение ключей памяти** (фолдинг): сливать
варианты контекста в один факт. Это и есть «вот оно» этой недели — не заклинание,
а измеренная граница.

## CALC-07b. BPE-орган: прогноз опровергнут, найден механизм включения

Прогнозы были заморожены в шапке скрипта ДО прогона (P1: γ_w2 > 0.0737;
P2: пересечение с char ≤3e9 ток; P3: критерий смерти).

- duty w2 @(0.90, N≥2) **плоско: 7.1→7.4% на всём окне 56K–3.6M ток (γ≈0.0007)**.
  **P1 ✗ ОПРОВЕРГНУТ** — наши окно и уровень абстракции w2 покрытие не растит.
  Пересечения с char-органом в домене нет (34.3% vs 7.4%).
- **Но**: надёжность w2 растёт с N круто: acc 0.734→0.896 на том же окне,
  фит acc(N) = 0.305+0.039·ln N → **acc=0.95 при ≈1.3e7 ток** — на Kaggle-ступени
  (62M) w2-орган включается младшим членом каскада с duty ≈7–8% (внахлёст частично
  с char). Механизм подтверждён CALC-02b (видано-МАССА w2 росла 2.5→13.9% — она
  про N≥1; duty требует N≥2 и уверенный топ — строже).

**Вывод-кристалл №2:** детерминизм живёт на мелкой грануляции; уровни абстракции
включаются скачками по мере надёжности, а покрытие дарит многоуровневый каскад с
фолдами на каждом уровне. Один «умный» орган дорогу не открывает.

## D. Лестница рычагов: чем закрыть «невиданость» ×13 (до s=0.95) и ×33 (0.98)

Невиданость сейчас 0.657. Нужно 0.05 / 0.02. Измеренные и плановые множители:

1. **Каскад уровней (B1)** — измерено: unseen ×0.90 (0.657→0.590). ✓
2. **Скидка масштаба на N≥2-фильтр** — синглтоны вымирают с N; измеряется
   на Kaggle (оценка ×0.85–0.95 сво.).
3. **Морфо-фолд** (лемма-ключи: «cats/cat», был/была/буду → один факт) —
   бумажный подсчёт CALC-08 (морф-сливалка словаря, дёшево, «на бумаге»).
4. **Джокер-фолд** (wildcard-позиции в ключе: «the ▯ cat sat» — маска на
   слоте переменной важности) — CALC-08, следующий по дешевизне.
5. **Семантические ключи** — кластеры контекстов из состояния самой
   умение-машины (мозговой ход: помним ситуации, не строки) — требует обученной
   машины → после визы H-33. Это главный кандидат на большой множитель.
6. **BPE-взрослая фаза** ≥1e9 ток — орган включается по мере плотности.

Каскад уже даёт ×4.3 данных; цель лестницы 3–5 — превратить её в множитель
невиданости ×13–33. Каждая ступень измеряется счётом текстов до любого прогона.

## E. Замороженные прогнозы на Kaggle-рубеж (×30 корпуса, ~62M ток) — публикуются ДО замера

- **K1**: char-c8 duty@acc≥0.95 = **47–52%** (фит γ: 49%).
  Смерть: вне [43%, 55%] → излом хвоста ≠ фиту, пересмотр модели.
- **K2**: каскад c8→c6→c4 duty@0.95 = **55–60%**. Смерть: <50%.
- **K3**: BPE-w2 младший орган достигает acc≥0.95 на Kaggle (фит 1.3e7 ток)
  и добавляет ≥+3 п.п. к каскаду сверх перекрытия. Смерть: acc<0.95 при 62М.
- Эти три цифры — калибровка излома хвоста: seen-power фит насыщается >1 при
  ~8.4e7 ток (нереально), unseen-power говорит 2.5e17 для 0.90 — правда между;
  одна точка ×30 решает, какая.

1. Экстраполяция γ на 4+ декады — допущение; Kaggle-замер (рубеж E) — единственный
