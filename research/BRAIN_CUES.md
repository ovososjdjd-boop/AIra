# BRAIN_CUES — речь, синестезия, вспоминание по крючку (запрос 2026-08-05)

Запрос заказчика: как устроен речевой центр мозга, как работает синестезия и как один
триггер вытаскивает связанные воспоминания — «понадобится для наших систем».

Этот документ: факты → перевод на наш субстрат → **явное решение открытой проблемы C5**
(recall без растущего KV-кэша) + новые гипотезы H-21/H-22. Ссылки — в LITERATURE.md,
кластер T.

## 1. Речь: «речевого центра» нет — есть два потока

**Факты (двухпоточная модель, Hickok–Poeppel 2000/2004/2007; обновление Hickok 2022):**
- **Р-1. Вентральный поток** (обе височные доли): звук → **смысл**; понимание. Семантика
  распределена широко по коре, «словарного склада» в одном месте нет.
- **Р-2. Дорсальный поток** (левая височно-теменно-лобная система, зона Spt): звук →
  **артикуляционный план**; сенсомоторный интерфейс. Ключевое: Spt генерирует
  **прогнозы того, что сейчас услышится** (forward predictions) — внутренняя
  предсказательная петля «произнёс → что должно прийти обратно».
- **Р-3. Двойная диссоциация клиникой:** синдромы Брока и проводниковая афазия — дорсальные;
  Вернике, словесная глухота — вентральные. Понимание и порождение — **частично разные сети
  с узким интерфейсом**, а не один узел.

**Перевод на субстрат (для M3/M6):**
- **Д1.** Архитектура носителя языка = два потока: «понимательный» (состояние-смысл, наш
  основной рекуррентный путь) + тонкая «порождающе-предсказательная» петля, которая
  непрерывно предсказывает *следующий вход*. Несовпадение = обучающий сигнал. Это буквально
  наш PC-остаток ε: мозг штатно содержит предсказатель следующего токена — MLM-цель
  встроена в проводку, а не навязана извне.
- **Д2.** Внутренний подголосок (репетиция, удержание фразы без понимания) — отдельный
  дорсальный контур → у нас: маленькая «эхо-зона» рабочей памяти вместо полного KV всей
  прошлой речи. Дешёвый буфер на ~фразу + смысловой стор = замена «помнить всё дословно».
- **Д3.** Критик M7 («старший брат») — третий мониторинговый поток: слушает собственный
  выхлоп через тот же сенсомоторный интерфейс. Клиника подсказывает, что самоконтроль
  физиологически отделён от производства — наше решение о *свежей перспективе критика*
  (ALIGNMENT §4) согласуется с раздельностью сетей.

## 2. Синестезия: дешёвое скрещивание кодов

**Факты (Ramachandran–Hubbard 2001; DTI Rouw–Scholte 2007; Neufeld et al. 2012; обзор Brang+):**
- **С-1. Два механизма, не исключают друг друга:** (а) кросс-активация — избыточная прямая
  проводка между соседними картами (дефект обрезки связей в развитии; графема → цвет в
  веретеновидной извилине); (б) расторможенная обратная связь — мультимодальный «нексус»
  (нижняя теменная кора) сильнее обычного подсвечивает одномодальные зоны. Связи для (б)
  есть у всех — меняется их *вес*, не топология.
- **С-2.** «Проекторы» (bottom-up, локальный перекрёст) vs «ассоциаторы» (top-down через
  теменной хаб) — два полюса одного механизма.
- **С-3. Мост Хебба:** одновременная активность укрепляет проводку — расторможенная
  обратная связь со временем *становится* проводкой. Пластичность превращает динамику в
  структуру (прямое следствие для нашего сна-консолидации).
- **С-4.** Обрезка (pruning) в развитии режет большинство перекрёстных связей; синестезия =
  остатки. Тот же механизм в малых дозах — субстрат метафоры и креативности (угловая
  извилина, абстрактные понятия).

**Перевод на субстрат:**
- **С1.** Связывание модальностей/зон дешевле делать **через хаб-зону с сильной обратной
  связью**, чем полной pairwise-проводкой: стоимость O(k) длинных связей вместо O(k²).
  Согласуется с rich club (FF-16) и нашей скелет-шиной.
- **С2.** Расписание «проросли густо → обрезали по порогу» для межзонных связей: и
  регуляризация, и энергоконтроль, и биоправдоподобие. Обрезка = сжатие ассоциативного
  бюджета до того, что реально используется.
- **С3.** HDC-биндинг (кластер O) — «легальная синестезия» по требованию: связанный
  гипервектор суперпозицирует модальности в одном коде; событие в одной зоне достраивает
  связанные коды соседних. Это ровно «один триггер → связанные воспоминания» на уровне
  представлений (см. §3).

## 3. Вспоминание по крючку: адресная книга + достройка

**Факты (Marr 1971; Treves–Rolls 1991–94; Rolls 2016; Staresina–Wimber 2019, TiCS; индексная
теория Teyler–DiScenna 1986):**
- **П-1. Разделение перед записью (DG):** входные коды разреживаются и ортогонализуются
  конкурентным обучением (в т.ч. за счёт случайности мшистых волокон) — похожие эпизоды
  получают максимально разные адреса, иначе интерференция.
- **П-2. Единый автоассоциатор (CA3):** все компоненты эпизода («что/где/награда»), бывшие
  активны одновременно, связываются рекуррентной Хебб-записью (есть и гетеросинаптический
  LTD, и разбавленная проводка — ёмкость и чистые бассейны притяжения). Запись одноразовая,
  со скоростью одного события.
- **П-3. Частичный крючок достраивает целое:** любой кусок («где») по ассоциативно
  изменяемым прямым входам (perforant path) запускает аттрактор, который восстанавливает
  остальные компоненты («что», «награда»).
- **П-4. Сжатый указатель и обратная распаковка (CA1 → обратные проекции):** CA3 выдаёт в
  CA1 сжатый retrieval-код, который по обратным связям **восстанавливает исходную корковую
  активность** (reinstatement). Поток на выборке *разворачивается*: крючок идёт прямым путём,
  воспоминание возвращается обратным. Хронометрия: достройка ~с 500 мс, восстановление в
  коре до ~1,5 с, тиканье тета-ритмом. Воспоминание = медленное событие, не такт.
- **П-5. Сначала «знаком/незнаком»:** медиальная височная кора выдаёт быстрый сигнал
  фамильярности до запуска гиппокампальной достройки; полное вспоминание — только если
  «знаком». Дешёвый фильтр против пустой работы (и конфабуляции).
- **П-6.** Контент живёт в коре, гиппокамп хранит **индекс** (указатели на ансамбли), не
  саму запись — память это адресная книга + умение заново собрать.

**Перевод на субстрат — это готовый чертёж ответа на C5 (см. §4):**
- **M-1. Запись:** сжатый код текущего состояния (у нас — HDC-вектор/разреженный код зоны)
  пишется в автоассоциативный стор одной локальной Хебб±LTD-записью. Цена = одно событие,
  O(1) по длине контекста — принципиальное отличие от трансформера, где прошлое
  физически лежит в KV и перечитывается каждый токен.
- **M-2. Чтение:** частичный крючок → несколько тактов релаксации аттрактора → достроенный
  код → обученный декодер (аналог backprojection) разворачивает его в рабочее состояние
  модели. Дорого — но платим только на факте, не на каждом токене.
- **M-3. Гейт знакомства до достройки** (П-5): дешёвый скаляр «я это видел?» — экономия и
  щит против галлюцинаций-достроек.
- **M-4. Ёмкость покупается ортогонализацией** (П-1): HDC-проекции уже делают ровно это —
  наш «мир фактов» пишется в почти ортогональные адреса, интерференция откладывается.
- **M-5. Разделение ролей:** синтаксис/локальный контекст — рекуррентный рабочий буфер
  (эхо-зона, Д2); факты/эпизоды — стор. Трансформер смешивает оба в KV; мозг — нет.

## 4. В чём наша проблема и как её решаем

**Проблема (C5, THEORY_OPEN; главный риск M3 по PROTO_ROADMAP):**
трансформер вспоминает прошлое, дословно таская его с собой (KV-кэш растёт с контекстом,
энергия/токен растёт, факты тонут в окне). Мозг делает наоборот: не хранит ленту — хранит
адресную книгу и **достраивает содержимое по куску-крючку**, платя только в момент
вспоминания. §1–§3 выше дают не метафору, а чертёж с измеренными параметрами.

**План решения (в порядке испытаний):**
1. **EXP-05 «Мир фактов → стор»** — ✅ пройдено в день постановки (2026-08-05):
   `experiments/EXP05_REPORT.md`. Итог: DAM-стор помнит 1,28·10⁴ эпизодов безошибочно
   (строгая acc 1.000), вспоминает ×10³–×10⁴ дешевле KV-скана, гейт фамильярности
   бесплатен и отсекает 100% незнакомых эпизодов; классическая sign-релаксация Хопфилда
   провалена (контрольный контраст 0.000) — строим DAM-выборку. H-21/H-22 → ✓ в границах.
   Следующий: EXP-06 (QA-батарея на живых текстах корпуса против KV-бейзлайна).
2. **Гейт знакомства** (дешёвый детектор до релаксации; метрики энергии/ложных достроек)
   → **гипотеза H-22**.
3. **Встройка в носитель M3:** маршрут «синтаксис → рекуррентный буфер; вопрос-факт →
   стор»; читающий гейт решает, куда идём (дёшево проверяется на QA-перплексии нашей
   батареи).
4. **Двупоточность (Р-факты)** при сборке M6: порождающая петля с forward-прогнозом как
   доп. локальная цель обучения (стык с C6/FF-15); критик M7 — третий поток (Д3).

**Честные оговорки:**
- Шаблонный мир лёгок: ppl 1,12 уже на M1 → «recall» нельзя валидировать перплексией,
  только QA-батареей с контролем утечки (фильтр уже стоит при генерации данными).
- Аттракторы **конфабулируют** при переполнении — смерть-метрика интерференции в H-21
  обязательна; гейт знакомства частично закрывает риск.
- Релаксация при чтении = латентность (мозг: 0,5–1,5 с!). Для интерактива приемлемо,
  для «рассуждения без памяти» — нет: стор для фактов, не для пошагового вывода.

## 5. Открытые вопросы (в THEORY_OPEN при первом тупике)

- OQ-1: как учить «CA1-декодер» (обратную распаковку кода в рабочее состояние) локально —
  варианты: тот же PC-апдейт по ε между достроенным кодом и реальным состоянием.
- OQ-2: ёмкость Хебб-стора на распределённых HDC-кодах при нашей плотности — есть оценки
  Тревеса-Роллса для разреженных бинарных, для гипермерных вещественных посчитать свои.
- OQ-3: сон-реплей как движение *индекса* в медленный каскад (а не только весов) — стык
  с H-07/H-11/H-20; мозг, похоже, консолидирует именно маршруты доступа.
- OQ-4: ре-входимость (re-entry) и тета-выборка: нужен ли нам глобальный такт выборки из
  стора или потянет событийный режим с асинхронными релаксациями.
