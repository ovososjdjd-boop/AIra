# S0-LM — сборка первой целой модели из кирпичей (план-наряд)

Статус: 🔬 наряд выписан (07.08), запуск — после вердикта K7 (EXP-14 пуск №6).
Веха: M4-мост между малыми стендами и Kaggle-этапом заказчика.

## 0. Зачем (одной фразой)

Доказать на стойке, что **всё дерево изобретений вместе** (а не по одному) даёт
языковую машину, которая при равном качестве с GPT-бейзлайном стойки обучается
и отвечает **заметно дешевле и быстрее** — с таблицей «качество ↔ скорость ↔
энергия», измеренной одним протоколом.

## 1. Состав (кирпичи — всё уже оплачено опытами)

| Кирпич | Откуда | Статус |
|---|---|---|
| **L0 — каскадная триггерная полка** (c32→w3→c16→w2→c8→w1→c4, θ рабочая 0.90–0.95) | EXP-15/15b | ✓ канон (доминирует плоскую форму; live 33.3%@0.946, гибрид −4.50%) |
| **L1 — зонная петля** CharMLP-ctx32, PC-обучение v3.2: β 1.0→0.1 · T(β) 32→64 (K1) · lr-рампа ×0.3 последней трети (K2) · BB+сторож энергии · freeze 3e-3 · eps 1e-2 · шина σ-δ θ=0.05 | EXP-10…13 | ✓ в воротах на лестнице 0.1–0.8M |
| **Закон lr(d) ≈ (96/d)^0.55** + маркер завышения (дрейф хвоста >1% при K2) | EXP-13 | ✓ |
| **Память-амбразура** (семантическая/событийная добавка поверх потока) | EXP-05/06 | 🌱 кирпич есть, интеграция минимальная (v0: окно-демонстрация) |
| **BPE-16k-glue** (стойка B) | EXP-16a | ✓ принят; S0 собирается ДВУМЯ сборками: A char-64 (регрессия законов) и B BPE-16k (дизайн Kaggle) |

## 2. Размер и знаменатель

- Корпус M1 (8.1M ids) антимонотонен по ёмкости: BP-лестница @2400 = 96→1.1071,
  256→1.1132, 512→1.1227 → **S0 собирается на зоне-96 (возможно дубль 256)**,
  суммарный бюджет 0.4–1.5M параметров (зона-96 ≈ 117k + голова/вход + полка
  не в параметрах обучения).
- **Бейзлайн**: GPT-lite стойки (exp03, d64L2-ctx64 / d96L3-ctx96) + BP-знаменатель
  той же зоны (уже есть по лестнице) — сравнение трёхстороннее на одних данных.

## 3. Протокол (один день стойки)

1. Обучить L1 зону-96 v3.2 @2400 на M1 (≈8 мин) — и BP-знаменатель сверить с
  таблицей (расхождение >0.5% = стоп, разбор).
2. Заморозить; собрать эскалатор L0(θ=0.90)+L1; прогнать valid-поток
  (~1 мин) — цифры покрытия/ppl в таблицу.
3. Снять инференс-экономику: доля позиций L0 (бесплатных), работа L1 на остатке
  (freeze-активность), итоговая активная цена/символ vs бейзлайн (формула из
  EXP-15: ×10.3 поверх сна; на live ×(1/0.67)).
4. Генерационный контроль: 4 затравки × 300 символов от L0+L1 эскалатора и
  бейзлайна, слепая сверка связности (протокол KL-дрейфа 2k — из долгов).
5. Вариант B: то же поверх BPE-ids (стойка B) — зона-96 переобучается на
  BPE-потоке (проверка переноса законов v3.2 на токенный алфавит — ключевой
  мост к Kaggle).

## 4. Ворота S0-LM

- Качество: ppl гибрида ≤ чистой зоны ×1.00 (у нас: ожидаем строго <, 0.995 по
  данным EXP-15b) и ≤ бейзлайна exp03-малой сборки.
- Экономия: активная цена/символ инференса ≤ 0.15× бейзлайна (учёт: доля L0
  бесплатна, остаток freeze 0.42 работы, шина сжата).
- Скорость: wall-time/символ инференса ≤ 0.5× бейзлайна стойки на CPU.
- Смерть-критерий: сшивка кирпичей ломает хотя бы одно их свойство
  (полка врёт поверх плохой зоны; зона не держит хвост после полки; память
  мешает хвосту) → разбор как отдельный эксперимент-инцидент.

## 5. Риски/страховки

- K7-вердикт может перекроить рецепт L1 на случай расширения до 2048 (на S0-96
  рецепт не зависит от K7 — первая декада, v3.2 стабилен → S0 НЕ блокирован).
- Оценка 2–3 ч процессорного времени суммарно (дробится звеньями по принципу
  §7 дорожной карты).
