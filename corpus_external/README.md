# corpus_external/ — реестр внешних корпусов

Внешние данные, загруженные вручную (HF из песочницы недоступен — дверь закрыта;
спасибо заказчику за загрузку). Каждый корпус: папка с данными + карточка + статус проверки.

Источники обхода блокировки HF (зафиксировать для истории): huggingface.co/raw/modelscope/gitee из песочницы недоступны;
GitHub Contents/Blobs API и codeload — доступны. Полный TinyStories в открытых GitHub-зеркалах не найден
(только код/токенизаторы); заменители выше закрывают ту же роль якорей.

## Правила добавления

1. Новый корпус — новая подпапка + строка в таблице + карточка происхождения.
2. Статус проверки обязателен: UNVERIFIED → VERIFIED (чем проверено) / REJECTED (почему).
3. Наставнические (synthetic teacher) данные всегда стартуют как UNVERIFIED —
   отравленный/ошибочный учитель учит ошибкам.

## Лоадер

`src/aira/extdata.py` — нормализатор: `load_opus46() → [{q, a, reasoning, category, difficulty}]`,
фильтрует мёртвые строки; опционально отсеивает не-латиницу и строки без `reasoning`.
