# corpus_external/ — реестр внешних корпусов

Внешние данные, загруженные вручную (HF из песочницы недоступен — дверь закрыта;
спасибо заказчику за загрузку). Каждый корпус: папка с данными + карточка + статус проверки.

## Реестр

| Корпус | Что это | Язык | Объём | Лицензия | Статус проверки | Назначение у нас |
|---|---|---|---|---|---|---|
| `opus46/` | SFT-набор с цепочками рассуждений (teacher: заявлен Claude Opus 4.6): GSM8K-стиль математика, логические задачки, немного кода | англ. | 9 633 диалога (3 сообщения: system/user/assistant + поле `reasoning`), 13,4 МБ | MIT (по карточке) | ⚠️ UNVERIFIED: спот-аудит арифметики на ~5 примерах верен; 2 мёртвые строки (assistant=None), 1 пустой reasoning; **перед обучением — программная валидация ответов** | (1) англоязычная батарея рассуждений для M3+ (многошаговая арифметика = тест рабочей памяти кандидата-носителя); (2) эталонный формат «обдумывания» для критика M7 (ALIGNMENT); (3) источник дистилляции на англ. треке (M4). **НЕ** для посимвольной русской предтренировки — иной язык, замусорит статистику |

## Правила добавления

1. Новый корпус — новая подпапка + строка в таблице + карточка происхождения.
2. Статус проверки обязателен: UNVERIFIED → VERIFIED (чем проверено) / REJECTED (почему).
3. Наставнические (synthetic teacher) данные всегда стартуют как UNVERIFIED —
   отравленный/ошибочный учитель учит ошибкам.

## Лоадер

`src/aira/extdata.py` — нормализатор: `load_opus46() → [{q, a, reasoning, category, difficulty}]`,
фильтрует мёртвые строки; опционально отсеивает не-латиницу и строки без `reasoning`.
