# benchmarks/ — M1 «Измерительная стойка v1» (старт: 2026-08-05)

## Разведка среды (факты, влияющие на план)

| Факт | Следствие |
|---|---|
| GPU нет, 2 CPU, 3 ГБ RAM, 20 ГБ диска | микро-обучение возможно (1–10M пар. на малых корпусах, CPU); лестница масштабов ждёт доступ к железу |
| Прямой выход в интернет ограничен: HF-данные НЕ видны; **pypi и github-архивы (codeload) доступны** | датасеты с HF недоступны → собственный процедурный корпус (`src/aira/corpus.py`) как носитель стойки; HF-корпуса подключаем позже в среде с доступом |
| numpy/matplotlib в `.venv` есть; torch ставится из pypi (см. ниже) | бейзлайн-трансформер ставим, когда дойдём до тренировки |
| **torch из pypi требует nvidia-* библиотеки даже для CPU-импорта** (download.pytorch.org заблокирован) | ставим `torch==2.1.2` с зависимостями (~2,5 ГБ) через `scripts/setup_env.sh`; numpy зафиксирован `<2` |
| RAPL/powercap в среде НЕТ | ватты недоступны → энергия только прокси (Дж-оценка по трафику/MAC), честные допущения в `src/aira/energy.py` |

## Решения по корпусу (вместо TinyStories)

**Генеративный корпус `src/aira/corpus.py`** (v0, детерминированный по seed):
- детский словарь и шаблонные истории (уровень TinyStories по духу, полностью под нашим контролем);
- слой фактов с вопросами-ответами (заготовка под «мир фактов» M5);
- этические мини-ситуации с метками (заготовка под батарею M7/ALIGNMENT);
- плюсы не только из-за блокировки: контролируемый мир = честные пробы one-shot памяти и
  поведения, нулевая утечка между задачами, воспроизводимость без скачиваний.

**Внешние корпуса (2026-08-06):** заказчик загрузил `opus46` (англ. SFT с рассуждениями);
поисковым обходом через GitHub API добавлены: `gsm8k` (реальный, с золотом — валидатор;
верификация opus46: 7 335/7 596 совп. с золотом, 261 строка в карантине), `wikitext2`
(настоящий английский), `russian_lit` («Война и мир», «Кавказский пленник» — настоящий русский).
Реестр и правила: `corpus_external/README.md`, лоадер `src/aira/extdata.py`.
TinyStories целиком в доступных зеркалах не найден — роль якоря реализма закрывают
wikitext2 (EN) и russian_lit (RU).
